Categories (cont.) — Edit & Delete

Edit Category:

Edit Category — fields pre-filled with current data
  • Names: Pre-filled in all 4 languages — edit any independently.
  • "Current Image": Shows uploaded image. Use "Change Image" to replace.
  • Sort Order: Change to reorder display on website.

Buttons: Update Category + Back

Delete Category:

  • Click Delete → SweetAlert confirmation appears.
  • Message: "Are you sure?" — cannot undo.
  • Options: Yes, delete! or Cancel.
  • Warning: If category has products, their display may be affected!
⚠️ Deletion is permanent and irreversible — always confirm before deleting.
